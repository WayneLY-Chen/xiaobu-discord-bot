## 之後要補的話

檔名自訂，加進 README 的「截圖」章節即可。可以考慮：實際多人聊天（看得出說話者識別）、`/settings view` 的 embed、`/help`。

## 注意

- **拍之前先確認畫面上沒有 Token、API Key 或不想公開的私人對話**，這個 repo 是公開的。
- 深色主題比較好看，寬度建議 600～900px。
- 這些截圖裡的頭像與橫幅版權保留，見根目錄 `LICENSE` 的「圖片素材例外條款」。
