# 截圖

README 使用的實際運行截圖。請用下列檔名存放，README 直接引用這些路徑。

| 檔名 | 內容 | 怎麼拍 |
|---|---|---|
| `profile.png` | Bot 個人資料卡（頭像、橫幅、簡介） | 在伺服器成員列表點小步 → 展開的資料卡 |
| `chat.png` | 實際聊天 | 在 AI 頻道跟小步對話幾句，最好有兩個人以上，能看出說話者識別 |
| `settings.png` | `/settings view` 的 embed | 有 Manage Guild 權限時輸入 `/settings view` |
| `help.png` | `/help` 的說明 | 任何人輸入 `/help` |

## 注意

- **拍之前先確認畫面上沒有 Token、API Key、或不想公開的私人對話**，這個 repo 是公開的。
- 深色主題比較好看，寬度建議 600～900px。
- 這些截圖裡的頭像與橫幅版權保留，見根目錄 `LICENSE` 的「圖片素材例外條款」。
